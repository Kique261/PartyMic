## 测试中发现的情况

新增 GUI 测试第一次在“混音录音必须有信号”断言失败：所选实际音乐会话当时没有在录音中产生信号，无法据此判断是播放器状态还是其他音源因素。保留日志 `preview-ui-initial.log`。修正测试方案，使用本程序自己的独立低音量 997 Hz 源，明确刷新并选择该源，先停止测试音再试听，重新通过完整流程。没有放宽信号断言，也没有用“播放完成”替代用户听感确认。

主观音质修复目前是针对已确认的旧版 25% 强压低行为做调整，并增加可重复的录音对比工具；未实现 AEC，未自动修改 Windows 通信设置、音频驱动增强或语音客户端降噪。建议按 [排查步骤](troubleshooting.md)进行耳机/音响及压低开关对比。

复现方法和每次升级的证据要求见 [development.md](development.md)。
