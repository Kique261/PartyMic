# 常见问题

## 找不到 CABLE Input 或 CABLE Output

先按 [安装说明](install.md) 安装官方 VB-CABLE 并重启，再点击 PartyMic 的刷新按钮。请选择标准立体声线路，不要选 CABLE In 16ch。

## 队友听不到音乐或人声

- PartyMic 中选择 CABLE Input，语音软件的麦克风选择 CABLE Output。
- 检查已经点击“开始混音”，输入没有静音，音乐和人声音量均非零。
- 确认 Windows 允许桌面应用使用麦克风，实体麦克风没有硬件静音。
- 按键说话模式需要自行按下语音键。语音门限可能截断较小的音乐。

## 找不到网易云，或切歌后没有声音

先实际播放一次音乐，再刷新并选择 `cloudmusic.exe` 或真正输出声音的软件进程。播放器重启后需要重新选择音源并开始混音。

## 音乐发闷、回声或讲话时音质下降

先关闭“说话时自动压低音乐”，降低过高的人声增益，再做两次对比：静音麦克风录一次数字音乐，恢复麦克风后再录一次。若只有后者发闷，音响中的音乐可能被麦克风再次收进来，请改用耳机。

PartyMic 目前没有软件回声消除。若本地录音清楚、只有通话失真，检查语音软件自己的降噪、自动增益、语音活动门限或音乐模式。

## 提示音能听到，录音回放听不到

暂停正在外放的音乐，确认试听输出选择实际耳机、HDMI 或扬声器，试听音量不为零。录音时人声音量不能为零，麦克风也不能静音。

可以点击“打开文件夹”，用系统播放器播放桌面的 WAV 文件。试听会先停止混音，结束后需要重新开始混音。

## 断音或卡顿

先关闭其他同时向 CABLE Input 输出的音频路由工具，检查设备连接和系统负载。停止混音、刷新并重新选择设备后再试；重启播放器后也要重新选择音源。

语音软件的降噪、语音门限和网络状态也可能影响队友听到的声音，可先用 PartyMic 的本地录音与通话效果做对比。

## 无法升级或卸载

先关闭 PartyMic 窗口，再运行安装或卸载程序。录音保存在桌面的 PartyMic录音 文件夹，卸载不会删除它们。

## 退出后，语音软件直接选择实体麦克风却无声

先确认 PartyMic 已完全退出，接着在 Windows“设置 → 系统 → 声音 → 输入”中选择 Brio 90 等实体麦克风，检查输入电平、输入音量和静音状态。也可用 Windows 录音机单独检查。退出 PartyMic 后不会替其他软件自动切换麦克风。

如果 Windows 能收到声音，只有语音软件无声，请在该语音软件中退出语音频道后重新加入，并重新选择实体麦克风；检查它自己的静音、按键说话和输入门限。将大致发生时间与 PartyMic 日志一起保留，便于区分设备采集和语音客户端问题。

若问题出现在启动或停止混音之后，请分别记下“停止混音”和“退出整个窗口”后的表现。保留日志后，可先退出 PartyMic，再用 Windows 输入电平或录音机检查实体麦克风。不要同时修改多处设备设置，以便确认哪一步恢复了声音。

## 运行日志与问题反馈

0.5.4 及后续版本可点击侧栏“打开日志文件夹”，或在资源管理器地址栏输入 `%LOCALAPPDATA%\PartyMic\Logs`。旧版本没有生成日志时，需要先升级。

日志记录程序版本、所选音源与设备标识、音频链路初始化及释放、录音/试听的开始结束、错误码，以及定期的帧数、界面心跳、内存和句柄计数。日志写入和运行监控分别使用独立线程，不依赖界面刷新。

0.5.5 及后续版本还记录所选采集设备的原生格式，以及订阅期间 Windows 通知的麦克风静音、音量变化和会话断开原因。这些记录用于排障，不会自动修改系统音量或其他软件的麦克风。

- 日志是本地文本文件，不包含音频、聊天内容或录音文件内容，不自动上传。
- 自动轮换，通常保留最近 5 个日志文件，每个约 2 MB；文件边界可能多出一条记录。
- 若再次卡住，先记下时间；恢复或退出后复制整个 Logs 文件夹留存，避免后续轮换覆盖。程序打不开时仍可从资源管理器复制。
- 反馈前可检查文本中的设备标识、音源进程名称等信息；日志按 UTC 时间并附系统运行时间计数记录。
- 系统断电、强制结束进程、磁盘故障或整个进程停止执行时，最后一些信息可能无法写入，日志不能保证记录所有故障。

关闭窗口会先请求停止并释放音频设备。若系统调用一直不返回，关闭等待 15 秒后程序会结束自身进程，记录退出超时；正在保存的录音可能不完整。

## 游戏或反作弊提示冲突

停止使用 PartyMic，保留游戏提示，通过官方渠道反馈。不要为使用本程序关闭或绕过反作弊、驱动签名验证或 Windows 安全功能。本项目不提供 LOL / ACE 认证或零封号承诺。
