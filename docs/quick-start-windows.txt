PartyMic 0.5.0 · Windows 11 x64

这是在 Fedora 上编译的 Windows 64 位桌面程序。新版改善数字音乐高频衰减与切页动效，侧栏包含混音、录音试听和使用指南；实际测试范围与 EXE 哈希见 docs/verification.md。真人通话主观音质及腾讯 ACE 兼容性尚未验收。

1. 安装官方 VB-CABLE，按安装程序提示重启。下载地址见 README.md。
2. 将 Windows 默认播放、默认通信播放、语音软件扬声器都设为耳机；不要选 CABLE Input。
3. 网易云音乐先播放一次，双击 PartyMic.exe，点击“刷新设备 / 软件”。
4. 音乐软件选择 cloudmusic.exe 或实际产生音乐的软件进程。
5. 实体麦克风选择摄像头对应的麦克风；虚拟声卡输入选择 CABLE Input。
6. 点击“开始混音”，在 LOL / 语音软件的麦克风设置中选择 CABLE Output。
7. 先通过 Windows 录音机或语音软件的麦克风测试，确认音乐和人声都有声音。
8. 音乐默认 25%，人声 100%。人声音量可调 0–200%，同时影响人声录音。自动压低默认关闭；开启后可调保留比例，默认 65%。
9. 停止按钮和关闭窗口均会停止混音；最小化继续工作。

录音与试听：
- 点击左侧“录音与试听”，选择“仅人声”，点击“录制 15 秒”并讲话。可提前停止保存。
- 想录网易云叠加效果：先开始混音，再选择“音乐 + 人声”录制。
- 录音保存在桌面的 PartyMic录音 文件夹，格式为无损 WAV，不上传。
- 试听输出选择实际耳机、HDMI 或扬声器，点击“试听刚才录音”。试听前会停止混音，结束后需手动重新开始混音。
- 也可点击“文件夹”，用系统播放器打开录音。试听音量只改变回放，不修改录音。
- 音响外放可能被麦克风拾回；若音乐发闷，关闭自动压低，并用耳机对比。当前没有软件回声消除。

EXE 不需要管理员权限，C++ 运行库已静态链接。VB-CABLE 驱动需要单独安装，未包含在此压缩包中。
不要开启麦克风或 CABLE Output 的“侦听此设备”，建议佩戴耳机。
语音软件的降噪、语音门限或按键说话可能影响音乐传输，请使用其官方设置调整。
未承诺 ACE 白名单或零封号风险；如游戏或反作弊提示冲突，停止使用。

详细说明见 README.md，实际验证记录见 docs/verification.md。
