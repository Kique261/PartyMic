# Windows 11 手工验收

以下是完整验收清单，不能整体视为已通过。2026-10-18，0.5.0 完成核心、合成音源频响、90 秒连续混音及 GUI 自动化，结果见 verification.md 和 test-results/windows-runtime.json。0.1.0 曾完成网易云实播及 60 秒连续混音，但本版实播采集为静音，尚未通过；仍需真人语音、长时间运行及游戏场景验收。记录 Windows 版本、音频驱动版本、VB-CABLE 版本、播放器版本、摄像头型号和语音客户端版本。

## 构建与权限

1. 在带 Windows 11 SDK 的 VS 2022 x64 工具链构建 Debug / Release，运行 CTest。
2. 在普通用户权限启动 EXE，确认不出现 UAC 提权、不需要关闭反作弊、不要求测试签名。
3. 在 100% / 125% / 150% 显示缩放、不同分辨率和双屏之间切换，确认控件可用且状态文本可读。

## 先在非游戏环境验证音频

1. 安装官方 VB-CABLE 并重启，Windows 默认及默认通信播放设为耳机。首次测试先使用低音量。
2. 网易云音乐正常向耳机播放，PartyMic 中选择对应进程、摄像头麦克风、CABLE Input。
3. Windows 录音机中选择 CABLE Output，录制音乐、说话以及两者同时发声；听回放确认两者都存在且无明显失真。
4. 音乐静音后只剩人声；麦克风静音后只剩音乐；两者静音后完全无声，静音麦克风不再触发自动压低。
5. 开启自动压低：说话时音乐渐降，停止说话后平滑恢复。关闭后音乐不随讲话改变。
6. 各调音滑块至 0%、25%、100%、200%，确认电平随之改变；较大输入不会出现超范围样本，主观上不应明显破音。
7. 同时播放另一软件、系统提示音，确认不会进入录音。浏览器源需特别检查其多个标签页的采集范围。
8. 语音软件扬声器选耳机；播放队友语音，确认不回流到虚拟麦克风。不打开「侦听此设备」。
9. 停止和关闭窗口后，录音机应不再收到 PartyMic 的人声或音乐；最小化时应继续工作。
10. 连续运行至少 60 分钟，记录丢帧计数、主观延迟、CPU、内存和卡顿；检查多个硬件设备时钟漂移的影响。

## 0.2.0 录音与试听

1. 默认不开启自动压低；打开后保留 25%、65%、100% 对比，关闭后讲话不影响音乐增益。记录外放和耳机两种结果，区分声学拾音与数字增益。
2. 未开始混音时，选择仅人声录音；人声音量 0% 应为静音，100% 应录到讲话，200% 应检查峰值与失真。
3. 验证 15 秒自动保存、提前停止保存、关闭窗口停止并保存部分录音；文件位于实际桌面文件夹。
4. 开始混音后录制“音乐 + 人声”；仅人声录音不应依赖 VB-CABLE，混音录音则必须使用标准立体声配对。
5. 选择实际 HDMI/耳机试听，确认播放前混音停止；试听中不得同时录音，停止后可再次播放，播放结束能恢复按钮状态。
6. 核对试听音量 0–100% 只影响回放，原文件哈希不变；试听设备列表没有 VB-CABLE 或 Steam Streaming。
7. 试听与网易云同时播放会互相掩盖，主观判断时暂停网易云；不要把没有听到或只听到提示音记为回放通过。

## 故障与恢复

音频算法变动后，在交互桌面运行 `windows_audio_smoke.exe --fidelity` 检查五个频点的完整数字路径幅度，再运行 `--run` 与 `--soak 90`。频响测试不等于房间拾音、失真、相位或真人听感通过。`windows_audio_effects.exe` 只查询私有流效果能力，不验证回声消除效果。

1. 摄像头拔出、VB-CABLE 被禁用：确认停止或出现可理解的错误，不崩溃；重新连接后刷新并重启音频。
2. 音乐暂停、恢复：麦克风应连续正常；关闭播放器后应停止并提示重新选择，不自动捕获其他应用。
3. 关闭播放器后重开：刷新并重新选择，验证子进程采集范围。网易云音乐升级后重复。
4. 初始化过程中立即点停止，重复 20 次；反复开始/停止 50 次，检查挂死、句柄增长及残留输出。
5. 拒绝 Windows 麦克风隐私权限、使用独占音频应用占用麦克风：确认显示初始化错误。
6. 系统默认或默认通信播放设为 CABLE Input：确认拒绝启动，恢复耳机后可用。
7. 切换系统默认设备、休眠唤醒、修改采样率后记录行为；本版允许要求手工刷新重启。

## 游戏与 ACE

先通过全部独立音频检查，再确认腾讯最新官方说明是否允许相应虚拟音频设备。没有公开说明时，向官方提供程序用途、所用 Windows API 和虚拟声卡信息咨询。无法通过本清单证明不会封号。

在得到允许的条件下，通过语音客户端麦克风测试及合规的实际使用验证输入设备、按键说话、降噪和语音门限。ACE 报冲突时停止测试并记录错误，联系官方；不关闭、隐藏或绕过 ACE。不得把一次无异常启动描述为 ACE 认证。
