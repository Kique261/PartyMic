## 中间失败与证据

原引擎与仅监视线程候选的 30 秒诊断分别有 960 / 1440 帧音乐欠载。按帧预填充后诊断欠载为 0，但观察端存在不连续；它们只有诊断完成标记，没有严格验收通过标记。

修正观察端后的首个 0.5.2 严格候选 Smoke 通过，Fidelity 在 8 kHz 检出 960 帧丢弃，Soak 约 21.016 秒检出 448 帧静音（约 9.33 ms）。随后增加输出缓冲和队列余量，才重新完整通过全部音频测试。保留 <1 ms 阈值，Soak 还要求观察端不连续为 0；未清空失败记录。更多数值见 JSON 的 `diagnostic_experiments` / `failed_attempts`。

完整数值日志和本程序窗口截图位于本地 `~/.local/state/partymic/continuity-20261019/`；远端按阶段分目录，最终程序和测试在 `%USERPROFILE%\PartyMicRemote\continuity-20261019\buffered`。录音只保存在 Windows 本地桌面，不进 GitHub 或发行包；公开结果去除了录音文件路径和设备实例标识。
