## 发现并修复的问题

初版自绘统一按消息号触发失效。Win32 滑块 `TBM_GETRANGEMAX` 与电平条 `PBM_SETPOS` 共享编号，导致绘制期间持续失效，UI 计时器饥饿；录音文件保存后，试听按钮未及时恢复，自动化失败。按控件类型限定消息后，空闲 CPU 恢复正常，并重跑完整录音试听、布局与硬件测试通过。失败日志保留在原始证据目录。小窗口截图还发现组合框打印会忽略局部区域，改为越过页头的控件整项隐藏。

原始日志和仅应用窗口截图在 Fedora `~/.local/state/partymic/remote-20261018/v0.3.0/`；Windows `PartyMicRemote\20261018\v0.3.0\tests`。私人录音只保存在 Windows 桌面 `PartyMic录音`，不加入发行包或源码包。

## 范围限制

本次没有重跑网易云专项、真人语音客户端通话或主观音质对比。0.2.0 的 90 秒连续混音为历史记录，本次没有重跑；没有 60 分钟稳定性、端到端延迟、热插拔、多显示器 DPI、屏幕阅读器或 MSVC 原生构建验收。未测试游戏 / ACE，没有兼容认证或零封号承诺；应用尚未 Authenticode 签名。混音、压低、录音和试听引擎未因本次外观改版修改。
