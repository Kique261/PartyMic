## 实现与测试中发现的问题

快速输入时，原生 trackbar 输入路径会直接绘制系统滑块，绕过主题缓冲；现在统一滑块输入和绘制，保留原生数值与父窗口通知。滚动时控件显示状态曾被先打开再隐藏，叠加位置像素拷贝造成闪烁；现在批量提交位置和显隐、禁用中间重绘与旧像素拷贝，并裁剪父子窗口绘制区域。

新增视觉脚本初次缺少 System.Drawing 编译引用，已修正；悬停测试也遇到真实鼠标仍在按钮内造成基线已处于悬停色的时序失败，失败原因记录于本页，改为先移出按钮再开始测量。随后在同一最终 EXE 上完整视觉与布局回归通过。主题现在同时处理 WM_PRINT 与 WM_PRINTCLIENT，避免单个控件捕获走回系统外观。

原始日志、动效帧和应用窗口截图：Fedora `~/.local/state/partymic/remote-20261018/v0.4.0/`，Windows `PartyMicRemote\20261018\v0.4.0\tests`。录音仅留在 Windows 桌面 `PartyMic录音`，不进入发行包或源码包。

本次没有受控人声主观听感、语音通话、网易云专项、60 分钟稳定性、端到端延迟、热插拔、多屏 DPI、屏幕阅读器或 MSVC 原生构建验收。系统关闭动画时的即时更新分支尚未在真机单独切换验收；页面滚动截图和像素测试不能替代用户在所有显示器刷新率上的观察。游戏 / ACE 未测试，无兼容认证；音频引擎未随本次 UI 修改，历史 90 秒连续混音结果保留在 0.2.0 记录。
