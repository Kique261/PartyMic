# 使用说明

## 将音乐和人声送入通话

1. 先在音乐软件中播放一次音乐，再打开 PartyMic。
2. 在“混音工作台”点击“刷新设备 / 软件”。
3. 音乐软件选择实际播放音乐的进程，例如网易云的 `cloudmusic.exe`。
4. 实体麦克风选择摄像头、耳麦或其他真实麦克风。
5. 虚拟声卡输入选择标准 **CABLE Input**，点击“开始混音”。
6. 在 LOL、Discord 或其他语音软件中，将麦克风设为 **CABLE Output**，扬声器设为实际耳机或音响。
7. 使用语音软件自带的麦克风试听，确认音乐和人声都能听到。

不要选择 `CABLE In 16ch`，不要把语音软件收到的队友声音再输出到 CABLE Input。推荐佩戴耳机，避免音响声音被麦克风再次拾入。

音乐仍通过音乐软件原来的设备播放，所以你可以正常听歌。停止混音或关闭窗口后，PartyMic 不再向虚拟麦克风发送声音；最小化会继续混音。

需要直接使用摄像头或耳麦通话时，请在语音软件中手动选择实体麦克风。若停止混音后实体麦克风无声，先保留日志，再按 [实体麦克风无声的排查步骤](troubleshooting.md#退出后语音软件直接选择实体麦克风却无声) 检查。

如果语音软件的测试没有按界面选择切换设备，而是跟随 Windows 默认输入，请到 **Windows 设置 → 系统 → 声音 → 输入** 手动切换：

| 使用场景 | Windows 输入 |
| --- | --- |
| PartyMic 正在混音，通话需要音乐和人声 | CABLE Output |
| 停止混音后，直接用麦克风通话 | Brio、耳麦或其他实体麦克风 |

实体麦克风和 CABLE Output 都可保持启用。“默认通信设备”与普通默认输入可能不同，需要核对上述输入页面。PartyMic 不自动切换系统默认设备；只有确实跟随默认输入的客户端才需要这一步。

## 音量与静音

| 控件 | 用途 |
| --- | --- |
| 音乐音量 | 调整队友听到的数字音乐，默认 25% |
| 人声音量 | 调整麦克风混音和仅人声录音，默认 100% |
| 静音音乐 / 麦克风 | 单独关闭对应输入 |
| 说话时自动压低音乐 | 开启后突出讲话，默认关闭 |
| 讲话时保留音乐 | 压低开启时的保留比例，100% 表示不压低 |
| 试听音量 | 只调节录音回放，不改变录音文件 |

音乐、人声音量可在 0–200% 调节。鼠标滚轮、拖动或键盘方向键均可调节滑块。若声音过响或失真，先降低对应输入音量。

## 录音与试听

1. 打开“录音与试听”。
2. 选择“仅人声”检查麦克风，或先开始混音再选择“音乐 + 人声”检查实际输出。
3. 点击“录制 15 秒”并正常讲话，也可以提前点击“停止录音 / 试听”。
4. 录音自动保存到桌面的 **PartyMic录音** 文件夹；点击“打开文件夹”可用系统播放器播放。
5. 选择实际使用的试听输出，点击“试听刚才录音”。可调整试听音量、提前停止或再次播放。

录音为无损 PCM WAV，不自动上传。试听前会停止混音，避免回放再次进入混音；试听结束后需要手动点击“开始混音”。

想单独听数字音乐时，先静音麦克风，再录制“音乐 + 人声”；对比结束后恢复麦克风。

## 音乐软件重启或设备变更

音乐软件退出后，PartyMic 会停止对应采集。重新播放音乐并刷新、选择音源，再开始混音。更换麦克风、耳机或 HDMI 设备后，也请停止并刷新设备。

遇到问题请查看 [常见问题](troubleshooting.md)。

## 本地运行日志

点击侧栏“打开日志文件夹”可查看本机的运行记录。再次出现无声或卡住时，记下时间并复制日志文件夹，详细方法见 [日志与问题反馈](troubleshooting.md#运行日志与问题反馈)。日志不会录制声音或自动上传。
